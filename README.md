# SLICEBOX for the FM-1 — browser emulator

An unreleased test build (0.1-dev) of SLICEBOX for the M-VAVE FM-1, compiled for the browser and running on a picture
of the FM-1's panel. Built on [fm1-base](https://github.com/charlesvestal/fm1-base) (MPL-2.0) and felucca-bsp.

Open the GitHub Pages link for this repository, press start, and play. See `HOW-TO-PLAY.txt` for the controls.
